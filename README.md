# Store Manager – Electronics Store

A responsive electronics store website built using Angular.

## 🚀 Live Demo

[View Live Website](https://store-manager-six-lovat.vercel.app/)

## 🛠️ Technologies Used

- Angular
- TypeScript
- HTML5
- CSS3
- Fake Store API

## ✨ Features

- Browse electronics products.
- View product details.
- Add new products.
- Responsive user interface.

## 💻 Run Locally

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
ng serve
```

Open `http://localhost:4200/` in your browser.
